# URBIS

Open AI that finds slums and informal settlements in any city from free satellite imagery and open building data. Runs on your own computer.

Install and run: see https://urbis.shreyam.me

```bash
curl -fsSL https://urbis.shreyam.me/install.sh | sh
cd urbis && ./urbis.sh      # opens http://localhost:8770
```

Guide: [docs/APP.md](docs/APP.md). Imagery: Esri World Imagery. Buildings: Overture Maps (Google, Microsoft, OSM). Place search: OpenStreetMap. Some training data is CC BY-NC: use outputs non-commercially unless you check each source.
